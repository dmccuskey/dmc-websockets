# dmc-websockets: the Demo Page

This branch holds the page at https://dmccuskey.github.io/dmc-websockets/ and nothing else: the HTML5 build of the example [`examples/dmc-websockets-html5`](https://github.com/dmccuskey/dmc-websockets/tree/master/examples/dmc-websockets-html5), built with dmc-websockets 1.5.0.

The files are generated. To change the page, change the example on `master`, build it for HTML5 (the example's README has the steps) and replace the files here.
